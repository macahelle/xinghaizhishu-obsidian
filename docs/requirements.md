# 星海知枢工作台需求基线

## 交付形态

- `星海知枢/`：深色与浅色 Obsidian 主题。
- `xinghai-workbench/`：本地社区插件，提供动态工作台。
- `test-vault/`：用于验收的独立 Obsidian 知识库。
- `release/`：主题、插件、工作区和模板的安装包。

## 桌面布局

- 左侧：保留 Obsidian 原生 Ribbon 与文件列表。
- 中央上部：固定目录星图，以 `00-Wiki入口` 为中心。
- 中央下部：日期、时钟、统计和四个工作模块。
- 右侧：日历、当日时间线、关联笔记和高频标签。

## 四个工作模块

1. 当前专注：展示当前目标、25/50 分钟选择、开始/结束与当日累计。
2. 进行中的项目：读取 `type: project` 且 `status: active` 的笔记；按任务完成率计算进度。
3. 今日三件事：读取当日日记对应标题下的前三条原生任务并支持勾选写回。
4. 最近笔记：按修改时间列出最近四篇可打开笔记。

## 数据约定

- 日记：`30-复盘沉淀/日记/YYYY-MM-DD.md`
- 周复盘：`30-复盘沉淀/周复盘/YYYY-Www-周复盘.md`
- 今日三件事标题：`## 今日三件事`
- 时间线：日记内以 `HH:mm` 开头的任务或列表项。
- 专注状态和每日累计：插件私有 `data.json`。
- 其余任务、项目和复盘信息：Markdown 与 Properties。

## 响应式要求

- 大屏：左侧原生栏、中央工作台、右侧信息栏三栏显示。
- 小屏：插件顶部提供“星图 / 工作台 / 日历 / 关联”标签，功能不删减。
