# 星海知枢主题视觉规格

## 设计语言

- 深色：黑蓝背景、低亮度星空、紫蓝强调色与半透明原生面板。
- 浅色：雾白背景、低饱和蓝紫星空、深蓝灰正文与清晰边界。
- 字体优先使用系统中文字体，代码字体使用等宽字体。
- 圆角、边框、阴影和悬停状态保持统一，正文区域优先保证可读性。

## 原生界面范围

- 覆盖 Obsidian 工作区背景、Ribbon、左右侧栏、标签页、文件树、Markdown 编辑/阅读视图、弹窗、菜单和状态栏。
- 不创建新的 DOM 组件或功能面板。
- 不强制改变用户侧栏宽度，不隐藏反向链接或其他原生/插件视图。

## 图像资产

- 深色背景：`星海知枢/assets/xinghai-starfield-dark.png`
- 浅色背景：`星海知枢/assets/xinghai-starfield-light.png`
- 两张图片必须由 `theme.css` 直接引用；未引用图片不得进入发布包。

## 响应式

- 小屏降低背景和玻璃效果成本，保持文本与控件可读。
- 不通过主题模拟桌面工作台，也不承诺插件功能的移动布局。
