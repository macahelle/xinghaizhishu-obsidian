# 视觉规格

唯一视觉基准：`assets/reference/obsidian-workbench-target-v2.png`（1586 × 992）。

## 布局测量

| 区域 | 参考尺寸 |
|---|---:|
| Ribbon | 47 px |
| 左侧文件栏 | 196 px |
| 右侧信息栏 | 258 px |
| 中央星图区 | 约 475 px 高 |
| 中央工作台 | 约 469 px 高 |
| 工作模块 | 2 × 2 等宽网格 |

## 单屏布局约束

- 桌面工作台必须使用正常网格流：中央区域固定为“星图行 + 工作台行”。
- 文件树、中央工作台和右侧信息栏必须各自占据 Obsidian 原生分栏，不允许用 portal、fixed 或 absolute 把整块工作台跨栏覆盖。
- 主要区域在 1229 × 768 验收视口内同时可见；右栏必须显示到标签区，四个工作模块必须全部露出。
- `position: absolute` 只允许用于星图节点、连线、装饰光效和进度条等局部图元。

## 设计语言

- 深色：黑蓝底、紫蓝星云、低透明玻璃卡片、紫色主强调与青色辅助强调。
- 浅色：雾白底、低饱和蓝紫星雾、深蓝灰正文、保持清晰边界与可读性。
- 圆角克制：主卡片 12 px，内部卡片 9 px，按钮 8 px。
- 交互控件必须保留 hover、active、focus-visible、空状态和错误反馈。
- 星空只覆盖底层；文字、任务与进度条区域使用半透明实底提高可读性。
