# 星海知枢 Obsidian 主题与工作台

“星海知枢”安装包由两部分组成：深浅双色 Obsidian 主题 `3.2.0`，以及配套工作台插件 `xinghai-workbench 1.2.6`。主题负责全局外观，插件提供星图、任务、项目、专注、日历和关联信息功能。

## 产品能力

### 主题

- 深色模式：紫蓝星海背景、深色半透明面板与高对比文字。
- 浅色模式：雾蓝星云背景、浅色面板与清晰阅读层级。
- 统一文件树、标签页、编辑器、弹窗、按钮、状态栏和关系图谱外观。

### 工作台插件

- 目录星图与工作台主页。
- 今日三件事、进行中的项目和最近笔记。
- 25/50 分钟专注计时与本周复盘入口。
- 本地日历、今日时间线、关联笔记和标签汇总。
- 左右侧栏收起后提供对应的一键展开入口；侧栏展开后使用 Obsidian 原生收起按钮。

## 安装

解压 ZIP 后，将两个文件夹分别复制到当前知识库：

```text
星海知枢           → 知识库/.obsidian/themes/星海知枢/
xinghai-workbench → 知识库/.obsidian/plugins/xinghai-workbench/
```

然后在 Obsidian 中启用“星海知枢”主题和“星海知枢工作台”社区插件。macOS 与 Windows 的完整步骤见 [INSTALL.md](INSTALL.md)。

## 发布内容

- `星海知枢/`：主题清单、CSS 和两张主题背景图。
- `xinghai-workbench/`：插件清单、`main.js`、`styles.css` 和八张运行资源图。
- `README.md`、`INSTALL.md` 和两份 DOCX 使用文档。

发布包采用 19 文件白名单，不包含 `data.json`、测试库、QA 截图、开发脚本或归档数据。

## 兼容性

- 主题版本：3.2.0
- 工作台插件版本：1.2.6
- 最低 Obsidian 版本：1.9.0
- 已在 Obsidian 1.13.7（macOS）验证插件加载和侧栏交互
- macOS 与 Windows 使用同一份 ZIP

## 数据与权限

主题只提供 CSS 和图片资源。工作台插件在本地读取知识库 Markdown 与元数据，并在用户明确执行新增任务、项目、日记或复盘操作时创建或修改 Markdown；它不依赖外部服务，也不上传知识库内容。插件运行配置保存在知识库内的 `data.json`，该文件不随发布包分发。
