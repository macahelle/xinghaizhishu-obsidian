# 星海知枢 Obsidian 主题

“星海知枢”是一个面向 Obsidian 的深浅双色外观主题。本次发布只包含主题，不包含社区插件、工作台、任务、项目、专注计时或日历功能。

## 主题能力

- 深色模式：紫蓝星海背景、深色半透明面板与高对比文字。
- 浅色模式：雾蓝星云背景、浅色面板与清晰阅读层级。
- 统一文件树、标签页、编辑器、弹窗、按钮、状态栏和关系图谱外观。
- 不读取、不修改、不上传知识库内容。
- 不依赖第三方社区插件。

## 安装

把 `星海知枢` 文件夹复制到：

```text
知识库/.obsidian/themes/星海知枢/
```

然后在 Obsidian 的“设置 → 外观 → 主题”中选择“星海知枢”。详细步骤见 [INSTALL.md](INSTALL.md)。

## 发布文件

- `星海知枢/manifest.json`
- `星海知枢/theme.css`
- `星海知枢/assets/xinghai-starfield-dark.png`
- `星海知枢/assets/xinghai-starfield-light.png`

正式 ZIP 仅包含上述主题运行文件、README、安装说明和两份主题文档。

## 兼容性

- 主题版本：3.2.0
- 最低 Obsidian 版本：1.9.0
- 已在 Obsidian 1.13.7（macOS）加载验证
- macOS 与 Windows 使用同一份 ZIP

## 数据安全

主题只提供 CSS 和图片资源，不包含 JavaScript，不会创建、删除或修改笔记。卸载主题不会影响 Markdown 数据。
