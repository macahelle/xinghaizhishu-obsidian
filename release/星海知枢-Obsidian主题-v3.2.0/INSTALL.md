# 星海知枢 Obsidian 主题安装说明

本包是 Obsidian 主题，不是独立应用，也不是社区插件。macOS 与 Windows 使用同一份 ZIP。

## 安装前

1. 确认 Obsidian 版本不低于 1.9.0。
2. 建议备份知识库中的 `.obsidian/appearance.json`。
3. 完全退出 Obsidian。

## macOS

1. 解压 `星海知枢-Obsidian主题-v3.2.0.zip`。
2. 在 Finder 中打开知识库；看不到 `.obsidian` 时按 `Command + Shift + .`。
3. 将整个 `星海知枢` 文件夹复制到 `知识库/.obsidian/themes/星海知枢/`。
4. 启动 Obsidian，进入“设置 → 外观 → 主题”，选择“星海知枢”。

## Windows

1. 解压 `星海知枢-Obsidian主题-v3.2.0.zip`。
2. 在资源管理器中开启“查看 → 显示 → 隐藏的项目”。
3. 将整个 `星海知枢` 文件夹复制到 `知识库\.obsidian\themes\星海知枢\`。
4. 启动 Obsidian，进入“设置 → 外观 → 主题”，选择“星海知枢”。

不需要管理员权限，也不要复制到 Obsidian 程序安装目录或 `%APPDATA%`。

## 深浅模式

- 深色：紫蓝星海背景与深色面板。
- 浅色：雾蓝星云背景与浅色面板。

在“设置 → 外观 → 基础颜色方案”中切换。

## 升级

1. 完全退出 Obsidian。
2. 用新版 `星海知枢` 文件夹覆盖旧主题目录。
3. 重新打开 Obsidian，确认主题版本和深浅模式显示正常。

## 卸载与回滚

1. 在 Obsidian 外观设置中切换到其他主题。
2. 完全退出 Obsidian。
3. 删除 `知识库/.obsidian/themes/星海知枢/`。
4. 重新打开 Obsidian。

主题不包含 JavaScript，不会删除或修改 Markdown 笔记。
