## 可见差异判断

- 参考图的工作台面板向左跨过中央分栏，形成装饰性叠放；该方式会覆盖文件树并在窄窗口溢出。
- 当前实现保留相同信息层级、星海风格和模块顺序，但将三栏固定在各自原生分栏内。这是针对“所有图层必须在一个屏幕”的明确产品约束所做的结构性调整。
- `position: absolute` 仅用于星图节点、连线、局部光效和进度条，不再用于工作台整块面板。
