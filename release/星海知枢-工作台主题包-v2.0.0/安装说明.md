# 星海知枢工作台主题包安装说明

## 完整安装

安装工作区预设前请先完全退出 Obsidian，避免应用退出时用旧布局覆盖新文件。

假设知识库名为 `Tmac`：

1. 将 `星海知枢` 整个文件夹放入：
   `Tmac/.obsidian/themes/星海知枢`
2. 将以下文件放入 `Tmac/00-Wiki入口/`：
   - `00-星海工作台.md`
   - `03-工作台视图.base`
3. 备份 `Tmac/.obsidian/workspace.json`，再将 `workspace-xinghai.json` 复制进去并重命名为 `workspace.json`。
4. 备份 `Tmac/.obsidian/graph.json`，再将 `graph-xinghai.json` 复制进去并重命名为 `graph.json`。
5. 打开 Obsidian，在“设置 → 外观 → 主题”选择“星海知枢”。

重新打开后应看到：

- 左侧为原有知识库文件树；
- 中央上方为可缩放、筛选和点击的真实知识星图；
- 中央下方为四模块工作台；
- 右侧为真实属性、大纲、反向链接、出链和标签。

## 深色与浅色

进入“设置 → 外观 → 基础颜色方案”：

- 深色：紫蓝星海、深色玻璃卡片；
- 浅色：雾蓝星云、白色高可读卡片。

两种外观由同一个主题提供，无需重复安装。

## 日常使用

- 点击“快速捕捉”进入资料收件箱规则；
- 点击“本周复盘”进入复盘沉淀；
- 点击“知识库总览”进入原有 Base 总览；
- “今日三件事”可直接勾选并保存；
- 项目、目录和当前专注均可点击进入真实笔记；
- “最近笔记”自动更新，无需手工维护。

## 回滚

1. 完全退出 Obsidian。
2. 将安装前备份的 `workspace.json` 和 `graph.json` 复制回 `.obsidian/`。
3. 打开 Obsidian，在“设置 → 外观 → 主题”重新选择原主题。

工作台笔记和 Base 都是普通文件，即使停用主题，链接、任务和最近笔记仍然可用。
