# 星海知枢 · Obsidian 工作台主题包

“星海知枢”不是单纯的星空背景，而是一套由三层共同组成的 Obsidian 工作台：

1. **主题层**：深色星海与浅色晨雾两套完整配色，覆盖标题栏、标签页、文件树、编辑区、属性、Base、图谱、弹窗和状态栏。
2. **布局层**：左侧知识库目录、中央“知识星图 + 今日工作台”、右侧关联信息的工作区预设。
3. **数据层**：使用原生 Markdown、任务、双链和 Base 构成可操作的工作台，不依赖 Dataview、Tasks 或其他社区插件。

## 工作台结构

- 左侧：保留 `00-Wiki入口 / 10-主题知识 / 20-工作流模板 / 30-复盘沉淀 / 80-系统资源 / 90-资料收件箱` 原有架构。
- 中央上方：Obsidian 原生全局关系图谱，按一级目录分色。
- 中央下方：
  - 当前专注
  - 进行中的项目
  - 今日三件事
  - 最近笔记
- 右侧：原生属性、大纲、反向链接、出链和标签。

“今日三件事”是真实可保存的 Obsidian 任务；项目和导航是真实双链；“最近笔记”由 Obsidian 原生 Base 自动读取最近修改的五条笔记。

## 文件说明

- `星海知枢/`：可安装主题文件夹。
- `工作台/00-星海工作台.md`：原生工作台内容。
- `工作台/03-工作台视图.base`：最近笔记数据视图。
- `工作台/workspace-xinghai.json`：桌面工作区布局。
- `工作台/graph-xinghai.json`：知识星图分组与配色。
- `工作台/appearance-xinghai.json`：主题启用配置。
- `INSTALL.md`：安装、切换深浅色与回滚说明。

主题文件本身只能控制外观，不能凭空创建 Obsidian 面板和任务数据。因此本包同时提供主题、工作区预设和原生工作台文件；三者安装后才是完整的“工作台式主题”。

## 兼容性

- 最低 Obsidian 版本：1.9.0
- 已按 Obsidian 1.12.7 的工作区结构制作
- 桌面端为完整三栏布局
- 窄屏自动切换为单列卡片
- 不覆盖移动端 `workspace-mobile.json`
- 不依赖社区插件
