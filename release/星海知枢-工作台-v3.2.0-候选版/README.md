# 星海知枢 · Obsidian 工作台主题包

“星海知枢”不是单纯的星空背景，也不是一篇模拟页面，而是一套由四层共同组成的 Obsidian 工作台：

1. **主题层**：深色星海与浅色晨雾两套完整配色，覆盖标题栏、标签页、文件树、编辑区、属性、Base、图谱、弹窗和状态栏。
2. **插件层**：本地插件按知识库一级目录动态生成星图，并提供专注计时、项目进度、今日三件事、最近笔记、日历、时间线和关联笔记。
3. **布局层**：左侧原生知识库目录、中央“知识星图 + 今日工作台”、右侧工作台信息栏。
4. **数据层**：使用原生 Markdown、Properties、任务与双链保存数据，不依赖 Dataview 或 Tasks。

## 工作台结构

- 左侧：保留 `00-Wiki入口 / 10-主题知识 / 20-工作流模板 / 30-复盘沉淀 / 80-系统资源 / 90-资料收件箱` 原有架构。
- 中央上方：动态读取一级目录生成知识星图，优先以 `00-Wiki入口` 为中心，节点可以打开真实目录或笔记。
- 中央下方：
  - 当前专注
  - 进行中的项目
  - 今日三件事
  - 最近笔记
- 右侧：日历、今日时间线、关联笔记和标签。

“今日三件事”是真实可保存的 Obsidian 任务，并带有保存中、成功和失败反馈；项目进度读取 `type: project`、`status: active` 笔记中的任务完成率；“最近笔记”读取真实修改时间。点击无日记日期时会先确认，不会在浏览日期时静默创建文件。桌面布局采用正常文档流：星图和四模块各占固定网格行，工作模块不会以浮层覆盖文件树、右栏或彼此。

## 文件说明

- `星海知枢/`：可安装主题文件夹。
- `xinghai-workbench/`：可本地安装的工作台插件文件夹。
- `工作台/00-星海工作台.md`：原生工作台内容。
- `工作台/03-工作台视图.base`：最近笔记数据视图。
- `工作台/workspace-xinghai.json`：桌面工作区布局。
- `工作台/graph-xinghai.json`：知识星图分组与配色。
- `工作台/appearance-xinghai.json`：主题启用配置。
- `INSTALL.md`：安装、切换深浅色与回滚说明。

主题文件本身只能控制外观，不能创建时钟、任务写回和动态日历。因此完整交付同时包含主题、插件、工作区预设和 Markdown 数据约定。

## 兼容性

- 最低 Obsidian 版本：1.9.0
- 已在 Obsidian 1.13.4 独立测试库验证
- 桌面端为完整三栏单屏布局
- 窄屏切换为“星图 / 工作台 / 日历 / 关联”标签页；工作台使用单列卡片，极窄窗口可一键收起侧栏，并通过常驻“恢复侧栏”入口还原收起前状态
- 不覆盖移动端 `workspace-mobile.json`
- 键盘可使用 `Tab` 操作主要控件，并可在移动标签上使用方向键切换
- 只需要安装本包自带的 `星海知枢工作台` 本地插件
